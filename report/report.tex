% ABSTRACT
% ==============================================================================
\begin{center}
{\Large{\bf{ABSTRACT}}}
\end{center}
\vspace{0.3cm}

Every semester at IIT Guwahati, foundational courses like MA102 (Linear Algebra and Multivariable Calculus) enroll over 900 first-year undergraduates. Across quizzes, mid-semester, and end-semester examinations, this generates more than 13,000 scanned pages of handwritten mathematics that professors and teaching assistants must grade by hand. Reading hundreds of pages of unconstrained, hurried student handwriting leads to severe cognitive eye fatigue and grading variance across evaluators. Our goal in this project is to build an assistive transcription system that converts raw scanned exam pages directly into clean, compilable \LaTeX\ documents, letting evaluators read clear typeset mathematics side-by-side with original scanned ink. Crucially, this is an assistive tool for transcription rather than an automatic grading system: grading authority remains entirely with human instructors, and our pipeline preserves all student errors verbatim without silently ``correcting'' them.

To address this challenge within the privacy constraints of university examinations, we deployed our models entirely on-premise on the PARAM Kamrupa Supercomputer at IIT Guwahati without relying on external commercial cloud APIs. We investigated three distinct architectural paradigms during Phase 1:
\begin{enumerate}[label=(\alph*)]
    \item \textbf{A Modular Dual-Head Hybrid Pipeline:} Combining Sauvola adaptive binarization, 1D vertical IoU line grouping ($\text{IoU}_{\text{vert}} \ge 0.35$), an algorithmic matrix parser (\texttt{MatrixGridParser}) using horizontal and vertical projection profiles, a dual-head dispatcher (TrOCR for cursive text and a custom 23.1M parameter DenseNet-Coverage model for mathematical formulas), and a 2D spatial Directed Acyclic Graph (DAG) for reading-order topological linearization.
    \item \textbf{A Monolithic Multimodal Vision-Language Architecture:} Utilizing Qwen2.5-VL-7B stabilized via Assistant Prefill Locking and repetition penalty calibration, which revealed a severe hardware memory ceiling on Tesla V100 GPUs (16GB VRAM) where uncompressed full-page self-attention matrices ($O(N^2)$ ViT complexity) trigger instant CUDA Out-of-Memory crashes.
    \item \textbf{A Multi-Band High-Resolution Slicing and Pushdown Automaton Stitching Architecture:} Our master solution that strips printed booklet instructions, divides the active answer canvas into three overlapping horizontal bands with an $8\%$ vertical safety buffer ($\approx 180\,\text{px}$), and processes each band at native resolution ($\text{max\_dim} = 1200\,\text{px}$). This delivers a $3.5\times$ higher token density per line while collapsing peak ViT self-attention memory from $1.30\,\text{GiB}$ down to $\approx 240\,\text{MiB}$, guaranteeing zero CUDA OOM errors.
\end{enumerate}

The transcribed slices are unified by an automated software engineering pipeline (\texttt{stitch\_latex\_parts.py}) featuring a Context-Free Grammar Deterministic Pushdown Automaton (DPDA) LIFO stack balancer, regex underscore masking (\texttt{ZZMATHBLOCKiZZ}), and direct compilation via embedded Tectonic (XeTeX) in under 5 seconds with a 100\% compilation pass rate. 

Evaluating on authentic IIT Guwahati MA102 examination scripts, our Multi-Band Slicing architecture achieves a breakthrough \textbf{88.24\% Word-for-Word Token Accuracy} (\textbf{11.76\% Token Error Rate}) on complete student mathematical proofs (Roll 240101079), capturing 100\% of the mathematical proof steps verbatim across all three vector subspace axioms. Furthermore, our empirical error analysis on Roll 240122044 identifies and resolves critical edge cases: eliminating conversational ``Over-Helpful Tutor'' hallucination priors via strict negative prompting, and suppressing blank-page autoregressive loops via a zero-cost Laplacian variance ink filter ($\sigma^2(\nabla^2 I) < 1\%$). These Phase 1 accomplishments establish a proven, scalable supercomputing workflow on PARAM Kamrupa, paving the way for Phase 2: supervised QLoRA parameter-efficient fine-tuning and INT4 quantization for high-throughput institutional deployment.
